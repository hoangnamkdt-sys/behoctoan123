# 🐱 Bé Học Toán - Web App PWA

Ứng dụng web toán học vui nhộn cho trẻ em, tích hợp giọng đọc tiếng Việt và biểu tượng chú mèo 3D sinh động.

## ✨ Tính năng chính
* 🧮 Phép tính cộng, trừ và hỗn hợp linh hoạt.
* 🏆 Hệ thống tính điểm và thưởng sao động viên bé.
* 🔊 Tích hợp đọc đề toán bằng giọng nói tiếng Việt.
* 📚 Lưu trữ lịch sử bài làm lên đến 100 phép tính gần nhất.
* 📱 Hỗ trợ PWA (Progressive Web App): Có thể cài đặt trực tiếp lên màn hình chính điện thoại Android/iOS.

## 🚀 Hướng dẫn cài đặt lên điện thoại
1. Truy cập trang web bằng trình duyệt **Chrome** (trên Android) hoặc **Safari** (trên iOS).
2. Chọn **Menu (dấu 3 chấm hoặc nút Share)** -> Chọn **"Thêm vào màn hình chính"** (Add to Home screen).
3. Ứng dụng sẽ tự động đóng gói ra màn hình chính dạng App độc lập.
